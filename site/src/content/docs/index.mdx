The Runbook is open source and self-hosted: one container with PostgreSQL, or
your own Cloudflare account. These docs cover the open-source server, the
`runbook` CLI, the MCP server, the REST API and the runbook language.

```yaml
metadata: { id: post-deploy-checks }
spec:
  defaults: { actor: agent }
  inputs:
    service: { type: string, required: true }
  steps:
    - id: check_health
      instructions: Call /healthz on ${{ inputs.service }} three times; pass on 200 within 500 ms.
    - id: compare_error_rate
      instructions: Compare the 5xx rate with the hour before the deploy.
    - id: summarize
```
