Events marked **People** are notices for people (approvers, assignees,
escalations). When one reaches no subscriber, the run page says so.

## The envelope

Every delivery is a `POST` with a JSON body of this shape. Payloads carry
identifiers, recipients, links and facts about the event, never
credentials or secrets.

| Field | Meaning |
| --- | --- |
| `id` | The event ID (`evt_…`). The same on every retry of the event: deduplicate on it |
| `type` | The event type |
| `version` | The envelope version, `1` |
| `created_at` | When the event happened, RFC 3339 UTC with milliseconds |
| `org`, `project` | The organization and project IDs |
| `execution` | The run: `id`, `title`, `runbook`, `runbook_version_id`, `runbook_version` and `url`; `null` for project events |
| `sequence` | The run event that caused it; orders one run's events. `0` when there is no run event |
| `data` | The event's own facts, below |

## Headers

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
| `User-Agent` | `TheRunbook-Webhooks/1` |
| `Runbook-Event-Id` | The event ID, as in the body |
| `Runbook-Event-Type` | The event type |
| `Runbook-Delivery-Id` | This delivery (`whd_…`); a redelivery gets a new one |
| `Runbook-Timestamp` | Unix seconds when this attempt was signed |
| `Runbook-Signature` | `v1=<hex HMAC-SHA256>`, one per active secret, comma-separated |

## Delivery rules

| Rule | Value |
| --- | --- |
| A delivery succeeds on | A `2xx` within 10 seconds |
| Retried on | Timeouts, connection errors, `5xx`, `408` and `429` |
| Failed at once on | Any other status, a redirect (never followed) or a target that fails the address checks |
| Retries stop after | 24 hours from the delivery's creation |
| Signature timestamp tolerance | 5 minutes |
| Secret rotation overlap | 24 hours, during which both secrets sign |
| A subscription is disabled after | 3 days of continuous failure |
| Delivery log kept | 90 days |
| Subscriptions per project | 20 |
| Subscription URL | At most 2,048 bytes |
| Signing secrets | Start with `whsec_`; shown once, on create and on rotate |

The wait before each retry doubles, up to a ceiling:

| Retry | Waits |
| --- | --- |
| 1 | 30 s |
| 2 | 1 min |
| 3 | 2 min |
| 4 | 4 min |
| 5 | 8 min |
| 6 | 16 min |
| 7 | 32 min |
| 8 | 64 min |
| 9 and later | 2 hours |

## Agents

### `agent.work_available`

Steps an agent may claim became ready: at the start of a run, after an
approval was decided, after a wait ended, or when an agent's lease lapsed.
Subscribe a launcher to it to start (or wake) an agent. `data.reason` says
why (`initial`, `approval_decided`, `timer`, `signal`, `auto_decision`,
`lease_expired` or `cleanup`); `data.params` is the runbook's
`spec.agents.params`, passed through untouched.

```json title="Example body"
{
  "id": "evt_01JD2X6Q2C4V7T9M3K8B5N1R0S",
  "type": "agent.work_available",
  "version": 1,
  "created_at": "2026-11-18T09:30:12.418Z",
  "org": "org_01JC0000000000000000000001",
  "project": "prj_01JC0000000000000000000001",
  "execution": {
    "id": "exe_01JD2X6PZ5R8E2W4Y6A0C3D5F7",
    "title": "Verify api",
    "runbook": "rb_01JC9Z0000000000000000000A",
    "runbook_version_id": "rbv_01JD0000000000000000000003",
    "runbook_version": 3,
    "url": "https://runbooks.example.com/v1/executions/exe_01JD2X6PZ5R8E2W4Y6A0C3D5F7",
    "web_url": "https://runbooks.example.com/x/exe_01JD2X6PZ5R8E2W4Y6A0C3D5F7"
  },
  "sequence": 4,
  "data": {
    "reason": "initial",
    "ready_steps": [
      { "step_run_id": "sr_01JD2X6Q1B3N5P7R9T1V3X5Z7A", "path": "check_health", "title": "Check health" }
    ],
    "params": { "repo": "acme/api", "workflow": "runbook-resume.yml" }
  }
}
```

### `lease.revoked`

A runner agent's decision lease on an approval ended: the agent decided
or abstained, a person decided first, the approval closed (an automatic
decision, a timeout, the run was cancelled or ended), or the lease was
released or expired. The runner stops that decision run. `data.reason` is
`agent_decided`, `agent_abstained`, `human_decided`,
`automatic_decision`, `approval_closed`, `released`, `expired` or
`admin_released`.

```json title="Example body"
{
  "id": "evt_01JD2X7B3C5D7F9H1K3M5P7R9V",
  "type": "lease.revoked",
  "version": 1,
  "created_at": "2026-11-18T09:47:03.120Z",
  "org": "org_01JC0000000000000000000001",
  "project": "prj_01JC0000000000000000000001",
  "execution": {
    "id": "exe_01JD2X6PZ5R8E2W4Y6A0C3D5F7",
    "title": "Release 2.4.0",
    "runbook": "rb_01JC9Z0000000000000000000A",
    "runbook_version_id": "rbv_01JD0000000000000000000003",
    "runbook_version": 3,
    "url": "https://runbooks.example.com/v1/executions/exe_01JD2X6PZ5R8E2W4Y6A0C3D5F7",
    "web_url": "https://runbooks.example.com/x/exe_01JD2X6PZ5R8E2W4Y6A0C3D5F7"
  },
  "sequence": 9,
  "data": {
    "lease_id": "clm_01JD2X7A1B3C5D7F9H1K3M5P7R",

  }
}
```
