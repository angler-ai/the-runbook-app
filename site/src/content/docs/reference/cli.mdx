### `runbook run start`

Start an execution

```text
runbook run start <RUNBOOK> [OPTIONS]
```

**Arguments**

- `RUNBOOK`: Runbook reference (&#60;runbook&#62;[@&#60;n|rbv_id&#62;]) Required.

**Options**

- `--project <PROJECT>`: Project ID or slug Required. Environment: `RUNBOOK_PROJECT`.
- `--input <INPUTS>`: Input parameter (key=val) Repeatable.
- `--field <FIELDS>`: Field parameter (key=val) Repeatable.
- `--tag <TAGS>`: Execution tag Repeatable.
- `--title <TITLE>`: Execution title
- `--idempotency-key <IDEMPOTENCY_KEY>`: Idempotency key
- `--wait`: Poll until the execution is terminal; exit 3 if it failed or was cancelled
- `--follow`: Stream the execution's events until it ends (implies --wait)
- `--json`: Output response as JSON

## `runbook sync`

Sync a repository folder of runbooks with a project (push from CI, pull to start)

```text

```

**Commands**

- [`push`](#runbook-sync-push): Publish a folder of runbook sources to its project as one batch (from CI); any invalid file refuses the batch
- [`pull`](#runbook-sync-pull): Write each runbook's latest published source to a folder (to start a repository from the app)

### `runbook sync push`

Publish a folder of runbook sources to its project as one batch (from CI); any invalid file refuses the batch

```text
runbook sync push <DIR> [OPTIONS]
```

**Arguments**

- `DIR`: Folder of &#60;runbook&#62;.yaml files (or of project folders, with --each-project) Required.

**Options**

- `--project <PROJECT>`: Project ID or slug (default: the context's project, else `default`) Environment: `RUNBOOK_PROJECT`.
- `--each-project`: Each subfolder of DIR is a project, named by its slug (--project is ignored)
- `--dry-run`: Validate and show what would change; change nothing
- `--prune`: Archive Git-managed runbooks that have no file in the folder
- `--commit <COMMIT>`: Commit recorded on new versions (default: $GITHUB_SHA, else `git rev-parse HEAD`)
- `--branch <BRANCH>`: Branch recorded on new versions (default: $GITHUB_HEAD_REF or $GITHUB_REF_NAME, else the checked-out branch)
- `--idempotency-key <IDEMPOTENCY_KEY>`: Idempotency key (one per project is derived from it)
- `--json`: Output the result as JSON

### `runbook sync pull`

Write each runbook's latest published source to a folder (to start a repository from the app)

```text
runbook sync pull <DIR> [OPTIONS]
```

**Arguments**

- `DIR`: Folder to write &#60;runbook&#62;.yaml files into (created if missing) Required.

**Options**

- `--project <PROJECT>`: Project ID or slug (default: the context's project, else `default`) Environment: `RUNBOOK_PROJECT`.
- `--each-project`: Every project you can read, each into DIR/&#60;project-slug&#62;/ (--project is ignored)
- `--json`: Output what was written as JSON
