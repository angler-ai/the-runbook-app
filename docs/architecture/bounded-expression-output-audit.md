# Bounded expression output audit

Date: 2026-11-09. T10 adds public `evaluate` / `evaluate_in` and bounded typed JSON output. This task does not authorize A4 adoption or claim actual runtime Wasm parity; those remain later implementation gates.

## Boundary and source identity

`runtime::evaluate_in` calls the private source-aware evaluator, then `output::materialize`, then checks terminal state before cloning cumulative statistics. Schema fingerprints are checked before dispatch. `evaluate` creates one session and maps budgets above 100,000 to `CostExceeded`; direct `EvalSession::new` retains its diagnostic contract. Neither API returns raw CEL values, callbacks, executable programs, or partially materialized JSON. Missing data and failed indexes retain the structured runtime errors.

The source-aware result supplies the canonical `BoundNode` even when the CEL value is a bound nullable record represented by Null. Materialization traverses that immutable node's descendants; it never derives provenance by comparing values, guessing an alias, or walking all bindings. Scalar leaves record Value, lists record Membership, and records record Membership for their keyset/presence, including empty records. Explicit bound Null records record Value; literal Null has no origin and creates no read. Existing evaluator reads deduplicate through the shared ReadTracker, preserving first-consumption order. Omitted optional record fields remain omitted; whole-record Membership carries their shape dependency without inventing absent leaf values.

PreparedRecord now contains only its bounded type name and shared fields. Its former origin/type fields are redundant because the canonical BoundNode is retained. `prepare_value` temporarily retains an unused `_origin` argument to avoid changing the bindings owner in this task; removal is a nonbehavioral coordinator cleanup.

## Accounting and allocation order

`OutputBudget` stores cumulative encoded JSON bytes and tree nodes in EvalSession. `check_capacity` first checks any existing terminal reason, then subtracts used counters from 65,536 bytes / 16,384 nodes and rejects depth above 32. Failure sets sticky OutputLimit without changing counters or fuel. `charge_output` checks those capacities, precharges `nodes + bytes`, and updates counters only after fuel accepts. A failed fuel charge does not count attempted units. A later failed piece does not refund successful earlier pieces: those bytes paid for actual scanning or prepared structure. No subsequent evaluation dispatch or materialization occurs after terminal failure.

Strings precharge one node and the two JSON quotes, then precharge raw UTF-8 byte length before scanning any bytes. The scan counts only additional JSON escape bytes: one extra for quote/backslash and short control escapes; five extras for other U+0000–U+001F bytes. Non-ASCII UTF-8 remains unchanged by serde_json's default compact JSON encoding. Escape expansion is separately checked/charged, and only then is the original string copied into the returned JSON tree. Thus successful string cost is exactly encoded bytes plus one node, not an extra scan charge. Raw length is at most 65,536 before a scan, so the escape sum is at most 327,680 and cannot overflow supported usize widths. A string that fails raw precharge is never scanned/copied; one that fails escape expansion is scanned under already-paid fuel and never copied.

Record key copies use the same content charging after their two quotes; keys are at most 128 bytes by the schema envelope. Object delimiters, commas, and colons and list delimiters/commas are charged on container entry. Child values are charged when visited. All successful output bytes are counted exactly once, including punctuation and key names; keys are not separate JSON tree nodes.

Scalars use a 64-byte stack buffer. Numeric formatting invokes serde_json only on an i64 or finite f64 through an allocation-free fixed writer, never on CEL collections/errors. Its deterministic representation agrees with the returned JSON Number, including negative zero and subnormals. Timestamp seconds/nanos are checked again, then the existing chrono date conversion and bounded numeric writes emit UTC RFC3339; the fraction loop has at most eight iterations. A timestamp occupies at most 30 content bytes. Timestamp/string copies occur after their full encoded-byte precharge. This fixed-size formatting may run before its final length charge, but performs no data-dependent heap allocation or unbounded scan. The scalar formatter refuses collections and every other CEL value kind.

## Traversal and cleanup bounds

`materialize` uses an explicit stack of frames containing one borrowed child iterator, completed JSON children, and at most one prepared object key. It does not push an input-width list of pending work, recursively serialize collections, clone input subtrees, or allocate a list from its original input length. The immediate child count supplies an O(1) lower-bound capacity check before visiting or recording a container. A 100,000-item list therefore fails with zero output-node charges, zero output-byte charges, and no child visits/reads. The public test also verifies evaluator fuel remains below ten units (the source-derived cost is two dispatch/lookup units).

The lower-bound check is not a reservation: subsequent child charges increment the same session counters exactly once. At most 16,384 nodes can be charged, including partial output; nodes are charged before JSON allocation. Completed array children are appended incrementally and object values inserted only after their node/key charges. Allocator capacity overhead is bounded by those logical node counts; the 65,536 limit describes encoded JSON size, not allocator overhead or serde_json Value layout. BTreeMap/Vec machinery operates only on this capped output.

At most 33 active container frames can exist transiently: the first child at depth 33 is rejected before allocating its JSON value. Valid outputs have depth at most 32 edges. Standard Vec capacity growth has a finite bound at that depth; it does not depend on collection width. Dropping completed or partial JSON uses Rust/serde_json's ordinary destruction at bounded depth and bounded node count. Temporary source references borrow storage retained by Bindings; no unvisited input tail is cloned or destroyed by rejection.

Collection arithmetic uses sealed ingress sizes (100,000 elements/list, 256 fields/record) and small fixed punctuation multipliers; string expansion arithmetic is preceded by the output-byte bound. General caller-supplied usize dimensions and arbitrary CEL values are not public inputs. Private guard fixtures deliberately exercise otherwise unreachable output-depth boundaries without relaxing schema or activation limits.

## Evidence and honest reachability limits

Public tests cover scalar exact fuel and one-less-fuel failures; integer/f64 extremes, subnormal and negative-zero output; UTC timestamp range/fractions/event-time repeatability; whole returned lists/records and exact read vectors; nullable record versus literal Null; absent optional fields; MissingValue and IndexOutOfBounds; fingerprint mismatch at zero cost; quote/control/multibyte encoded-byte boundaries; repeated output reaching exactly 65,536 bytes; repeated empty records reaching exactly 16,384 nodes; output/read/fuel/cancellation terminal reuse; and 100,000-item rejection before child traversal. Private tests cover nonfinite/invalid time rejection, terminal precedence before raw-value inspection, unchanged counters after failed precharges, zero visited output-node counter on an oversized collection, and depth 32/33 conversion.

The public closed acyclic schema has depth 16, so public well-typed values cannot reach the output depth 32/33 boundary; that guard is defense in depth and is tested privately. A large unique-leaf result may hit 4,096 distinct reads or fuel before 16,384 output nodes. The cumulative empty-record test reaches the node cap through public APIs without weakening those earlier protections. Encoded-byte assertions use independently hand-counted cost fixtures and JSON serialization as a separate representation oracle. Native/Wasm runtime differential coverage, template rendering, independent implementation review, and engine revision production remain later tasks.

## T11b private handoff

- `runtime::evaluate_raw_with_source` gives a scalar plus optional canonical node without output allocation/counting.
- `output::scalar_text(&cel_core::Value)` returns a borrowed string or fixed-size owned stack buffer via `.as_str()`; collections fail TypeError.
- `output::charge_output(session, nodes, bytes, depth)` lets Text pay one node and two quotes once.
- `output::charge_json_string_content(session, fragment)` prepays the raw scan and escape expansion; copy/append only after success.
- For actual scalar results with a source, record Value via `session.reads.record(&source.origin, ReadKind::Value, &session.budget)`, including bound-null records. Literal Null has no source. Existing primitive reads deduplicate. Rejected non-null collections must not enumerate descendants.
- WholeValue should use `evaluate_in`; Text should not materialize each segment or pay per-segment JSON quotes/nodes. Shared counters, reads, fuel and terminal state persist across the complete render and later session reuse.
